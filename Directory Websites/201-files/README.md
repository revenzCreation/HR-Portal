# 201 Files

This directory is the front-end for the employee 201 file index.

## Record contract

The future authenticated backend should return records in this shape:

```json
{
  "surname": "DELA CRUZ",
  "firstName": "JUAN",
  "middleInitial": "P",
  "suffix": "JR.",
  "dateHired": "2026-01-15",
  "directLink": "https://secure-backend.example/201/record-id"
}
```

The page displays names as `SURNAME SUFFIX FIRSTNAME`. Middle initials are intentionally ignored. A missing `dateHired` remains blank. `directLink` opens in a new tab and should be a short-lived authenticated URL generated by the backend.

## MEGA integration boundary

Do not place a MEGA master key, session token, or private folder credentials in `js/app.js`, `js/records.js`, or any browser-delivered file. The future integration should use a server-side endpoint that authenticates HR Staff / Personnel, reads the approved MEGA directory, extracts the employee metadata, and returns only the directory fields plus short-lived file links.

The current page has no employee records until that secure connector is configured.
